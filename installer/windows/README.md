# このフォルダについて / About this folder

`aruaru-db.iss` はこのインストーラーを**作るための** [Inno Setup](https://jrsoftware.org/isinfo.php)
ビルドスクリプトです。`aruaru-db-installer.exe` はこのフォルダ内に実体として置いてあります
(ユーザー指示により、ローカルビルドしたバイナリを直接コミット)。

**⬇ 今すぐダウンロード**: [aruaru-db-installer.exe](aruaru-db-installer.exe)

**正直な開示**: このファイルはビルド成果物であり、`aruaru-db.iss`やソースコードを変更しても
自動的には更新されません(手動での再ビルド・再コミットが必要)。[常に最新版が欲しい場合は
GitHub Releasesも参照してください。](https://github.com/aon-co-jp/aruaru-db/releases/latest)

---

`aruaru-db.iss` is the [Inno Setup](https://jrsoftware.org/isinfo.php) build script used to
**produce** this installer. `aruaru-db-installer.exe` itself is committed directly into this
folder (per explicit user instruction, a locally-built binary is committed as-is).

**Honest disclosure**: this file is a build artifact. It does not update automatically when
`aruaru-db.iss` or the source code changes (a manual rebuild + recommit is required). [If you
always want the latest version, also check GitHub Releases.](https://github.com/aon-co-jp/aruaru-db/releases/latest)
